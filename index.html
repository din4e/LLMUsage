ABOUT

关于 LLM Usage

v0.1.4

LOCAL · PRIVATE · LIVE

本地、私密、实时的 LLM 用量仪表盘

在一个桌面窗口里集中查看各家大模型供应商的今日用量、每日趋势、套餐额度、余额、成本估算与冷却时间。凭据仅保存在本机，按需直接请求供应商官方接口，不经过任何第三方服务器。

当前版本0.1.4由 Tauri 配置提供

SECURITY

隐私与安全

  • 密钥由 Windows DPAPI 加密保存，仅当前 Windows 用户可解密。
  • 凭据不写入数据库或日志，仅在同步与你主动查看配置时解密。
  • 每日用量以非敏感日汇总形式保存在本地，仅用于趋势图。
  • 所有网络请求仅指向你配置的供应商域名，可在开发者工具中核对。
